Beschreibung:

Reformats Bossmods Bar Timers into a Timeline Style.

Some features:

  • Works across all versions of the game
  • Timeline with multiple different styles and Themes.
  • (optional) Full DBM and BW support - turn their timers into a timeline.
  • (optional) Visual tick every 5 seconds with a highlight.
  • (optional) BigIcon and or text appears during the last 5 seconds of a bar.
  • (optional) Auditory 5→1 countdown for timers.
  • Positioning via edit mode.
  • Extensive settings for icons, BigIcon, timeline, and text.
  • Changeable travel direction.
  • (optional) Pull timer and readycheck added to the timeline. (includes a Smart /pull feature: automatically picks duration depending on dungeon vs. raid)
  • (optional) Support for timeline icons (e.g., dispel type shown as icon borders).
  • Customizable highlights for specific remaining durations (change text color, add glow).
  • (optional) Vertical timeline (has no text).
  • (optional) Integrated reminders that can be created directly from the Encounter Journal or imported directly from external tools like mrt or Viserio.

And much more.

To get started simply log into the game which will start a guided tour. Alternatively you can start it using /at tour. You can see a preview in the edit mode or by clicking show test timers the settings (enter them using /at or via the button in the blizzard settings).
